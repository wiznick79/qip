01 / The workflow

A case, not just a chat.

Keep the question, its sources, and the final decision together—from the first observation to closure.

  1. 01

    Capture the incident

    Link a case to equipment. Record severity, observations, and source-attributed evidence.

  2. 02

    Bring the documents

    Upload PDF or text manuals. QIP extracts page-aware passages and indexes them for search.

  3. 03

    Ask with evidence

    Search selected documents, ask a bounded question, and open the cited source pages.

  4. 04

    Review and close

    Propose a finding, record a review, then close the investigation and export its PDF report.

03 / Following the evidence

How an answer gets its sources.

Retrieval-augmented generation combines document search with a local language model. Expand each stage for the engineering detail.

01 Extract and index

PDFBox extracts text with page numbers. Bounded, overlapping passages receive embeddings and PostgreSQL full-text indexes. Duplicate uploads reuse their checksum identity.

02 Retrieve relevant passages

Semantic and lexical rankings are combined using reciprocal rank fusion. Document filters constrain both searches; exact alarm codes complement similarity by meaning.

03 Generate within a bounded context

The answer adapter receives only the selected, size-bounded passages and a versioned prompt. Document text is treated as untrusted data, not as instructions.

04 Validate and inspect

Citation identifiers must belong to the retrieved passage set. The application distinguishes grounded answers, insufficient evidence, and technical failures. Citations let the reader inspect the original source; a valid citation alone does not establish that a conclusion is correct.

04 / Built to be inspected

The engineering is part of the project.

Repeatable evaluation

Deterministic adapters keep normal tests offline. Versioned RAG fixtures check retrieval, citations, insufficient evidence, and adversarial inputs.

A portfolio project with explicit limits.

QIP uses synthetic cases and documents. It is not machinery-control software or a certified diagnostic system. Enterprise identity, multi-tenancy, OCR, and external industrial integrations remain outside the current scope. Generated answers require source inspection and review.

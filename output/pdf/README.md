# Synthetic PDF fixtures

These documents describe entirely fictional equipment and contain invented operating values. They are intended for QIP upload, extraction, indexing, retrieval, citation, and UI demonstrations only. They must not be used to operate or maintain real machinery.

The PDFs are generated by `scripts/generate-synthetic-pdfs.py` using ReportLab. No third-party text, branding, diagrams, or proprietary source material is included.

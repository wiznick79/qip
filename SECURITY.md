# Security policy

## Supported versions

QIP is a pre-1.0 portfolio project. Security fixes are applied to the latest release and to `main`; older snapshots are not maintained.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not include exploit details, uploaded documents, credentials, model prompts, or other sensitive data in a public issue.

If private reporting is unavailable, open a minimal public issue asking the maintainer to establish a private contact channel. Include no vulnerability details until that channel is available.

Reports should identify the affected release or commit, the observable impact, safe reproduction prerequisites, and any suggested mitigation. Synthetic proof-of-concept data is preferred.

This project is decision-support software and is not approved for controlling machinery or making autonomous safety, quality, or root-cause decisions.
